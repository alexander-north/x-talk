# Reporting security issues

Report suspected vulnerabilities privately through GitHub's **Security → Report a vulnerability** for this repository:

https://github.com/alexander-north/x-talk/security/advisories/new

GitHub makes private reporting available for public repositories. The maintainer should enable it when making the repository public, before announcing the release. If that button is unavailable, open a minimal issue requesting a private contact route without describing the vulnerability or including exploit details, credentials, recordings, or transcripts.

Include the affected version/build, reproduction steps, impact, and a minimal non-sensitive example. Do not submit other people's data. Maintainers respond as availability permits; no response-time guarantee is offered. Fixes target the latest release; older versions do not have separate maintenance branches.
